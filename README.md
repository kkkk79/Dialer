# Simple Dialer

Dark-themed Android dialer app. Material dark UI, #121212 background.

## Features
- Full dialpad with haptic feedback
- Contacts list with search
- Call log (last 100 calls) with incoming/outgoing/missed icons
- tel: intent support (opens from links/other apps)
- Long press backspace = clear all

## Build
Requirements: Android Studio Hedgehog or newer, JDK 17+

1. Open project in Android Studio
2. Sync Gradle
3. Build > Generate Signed APK or Run on device

## Permissions
- CALL_PHONE — make calls
- READ_CONTACTS — contacts list
- READ_CALL_LOG — call history

## Min SDK
Android 8.0 (API 26)
